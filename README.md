# My Pokedex

A simple Pokedex CLI built in Go using [PokeAPI](https://pokeapi.co/).

## Run

```sh
go run .
```

You'll need Go and an internet connection.

## Commands

- `map` / `mapb` — browse location areas
- `explore <area>` — list Pokemon in an area
- `catch <pokemon>` — try to catch a Pokemon
- `inspect <pokemon>` — see a caught Pokemon's stats
- `pokedex` — list caught Pokemon
- `help` / `exit` — show commands or quit

Run tests with `go test ./...`.
